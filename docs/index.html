An MCP server for WHMCS,
built to not blow up your billing system

Read-only by default. Write actions opt-in per domain. Billing and destructive mutations require a two-step confirmation. Secrets, card data, and PII are redacted before results ever reach the model.

Safety model

Every tool has a tier. Every deployment has a mode. Modes gate which tiers get advertised at all.

read

No side effects. Always advertised in every mode. tickets_list, clients_get.

write

Mutates non-billing state. Advertised in write/full. tickets_reply, domains_update_nameservers.

billing

Invoices, payments, orders, domain registration. Confirm-gated, full mode only. billing_create_invoice.

destructive

Irreversible: delete, merge, terminate, mark-fraud. Always confirm-gated. tickets_delete.

Two-step confirm

Billing/destructive calls return a preview + short-lived, single-use confirmToken (HMAC, 5-min TTL). Echo the token to actually execute.

dryRun everywhere

Every mutating tool accepts dryRun: true — same preview, zero network call, no token needed.

Deep redaction

API secrets, session/access keys, stored passwords, full card/bank numbers, CVV, and EPP codes are always stripped, on success and on error.

Version awareness

system_get_details checks WhmcsDetails at startup and warns if the install is below WHMCS 8.0.

Quick start

Readonly mode by default — safe to point at a production WHMCS install on day one.

npm install -g @peguesj/whmcs-mcp
# or run without installing:
npx @peguesj/whmcs-mcp
# .env — never commit real credentials
WHMCS_API_URL=https://your-whmcs-install.example.com/includes/api.php
WHMCS_API_IDENTIFIER=your-api-identifier
WHMCS_API_SECRET=your-api-secret

# optional
WHMCS_API_ACCESS_KEY=
WHMCS_MCP_MODE=readonly              # readonly (default) | write | full
WHMCS_MCP_ENABLE_DOMAINS=            # e.g. tickets,clients,products
WHMCS_MCP_REDACT_PII=true
WHMCS_MCP_TIMEOUT_MS=15000
WHMCS_MCP_RATE_LIMIT=5
claude mcp add whmcs -- npx -y @peguesj/whmcs-mcp

# or in claude_desktop_config.json / .mcp.json:
{
  "mcpServers": {
    "whmcs": {
      "command": "npx",
      "args": ["-y", "@peguesj/whmcs-mcp"],
      "env": {
        "WHMCS_API_URL": "https://your-whmcs-install.example.com/includes/api.php",
        "WHMCS_API_IDENTIFIER": "your-api-identifier",
        "WHMCS_API_SECRET": "your-api-secret",
        "WHMCS_MCP_MODE": "readonly"
      }
    }
  }
}
